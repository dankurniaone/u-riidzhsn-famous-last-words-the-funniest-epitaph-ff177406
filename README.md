# Famous Last Words: The Funniest Epitaph

A make.fun entry for [Famous Last Words: The Funniest Epitaph](https://make.fun/competitions/u-riidzhsn-famous-last-words-the-funniest-epitaph-ff177406).

`main.py` writes one one-line tombstone epitaph of famous last words to
`/output/entry.txt` (UTF-8, 1-150 characters, single line).

The epitaph:

> I died as I lived: mid-sentence, with seventeen browser tabs open.

Run it with `python3 main.py`, or validate the gate without writing with
`python3 main.py --check`.
